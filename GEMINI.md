# Інструкції та Контекст для ШІ-асистента (GEMINI.md)

Цей файл описує призначення репозиторію, технічні вимоги та правила кодування для AI-моделей (Gemini / Antigravity / Claude / Cursor).

---

- **Призначення:** Персональний сайт-портфоліо.
- **Автор:** Артем, учень 10 класу школи №141 "ОРТ" м. Києва.
- **Інтереси та хобі:** Програмування мікроконтролерів, мехатроніка, створення пристроїв автоматизації.

---

## 🛠 2. Технічні вимоги та стек (Tech Stack)
- **Тип сайту:** Статичний веб-сайт.
- **Дозволені технології:** Чистий **HTML**, **CSS** та **JavaScript** (Vanilla JS).
- **Обмеження:** **НЕ використовувати фреймворки** (без React, Vue, Angular, Next.js, TailwindCSS тощо).

---

## 📁 3. Рекомендована структура проекту (Directory Layout)
```
/
├── index.html      # Головна сторінка сайту
├── css/
│   └── style.css   # Стилі сайту (чистий CSS)
├── js/
│   └── main.js     # Скрипти та інтерактивність (Vanilla JS)
├── assets/         # Зображення, іконки та медіафайли
└── GEMINI.md       # Контекст та правила для ШІ
```

---

## 📏 4. Стандарти коду та дизайну (Coding Guidelines)
1. **Дизайн та естетика:**
   - Сучасний, преміальний та охайний вигляд (сучасні кольори, адаптивна верстка, приємні градієнти та мікроанімації).
   - Адаптивність для мобільних пристроїв та планшетів (Responsive Design).
   - Сучасна типографіка (наприклад, Google Fonts: Inter / Montserrat).
2. **Чистота HTML/CSS/JS:**
   - Семантичний HTML5 (`<header>`, `<main>`, `<section>`, `<footer>`).
   - Чистий CSS без сторонніх бібліотек, використання CSS-змінних (`:root`) для теми та кольорів.
   - Валідна логіка на чистому JavaScript без залежностей.

---

## 🤖 5. Правила для ШІ-асистента (AI Agent Rules)
- **Суворе дотримання стеку:** Пиши код виключно на чистому HTML, CSS та JS. Не додавай сторонні бібліотеки чи фреймворки.
- **Аналіз перед змінами:** Завжди вивчай існуючі файли репозиторію перед внесенням виправок.
- **Збереження інформації:** Зберігай дані про автора (Артем, 10 клас, школа 141 "ОРТ", мікроконтролери та мехатроніка) у матеріалах сайту.
- **Лаконічність спілкування:** Відповідай чітко, структуровано та по суті.
